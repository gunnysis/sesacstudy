# bikerental-data

서울 공공자전거(따릉이) 대여 이력 학습용 데이터셋입니다.

## 파일 구성

| 파일 | 추적 여부 | 크기 | 행 수 | 설명 |
|------|:--------:|------|------|------|
| `bike_rent_1.csv` | ❌ git 미포함 | ~23MB | 400,000 | 대여 이력 (분할 1) |
| `bike_rent_2.csv` | ❌ git 미포함 | ~23MB | 399,962 | 대여 이력 (분할 2) |
| `bike_rent_3.csv` | ❌ git 미포함 | ~24MB | 400,000 | 대여 이력 (분할 3) |
| `bike_rent_4.csv` | ❌ git 미포함 | ~24MB | 399,953 | 대여 이력 (분할 4) |
| `bike_rent_5.csv` | ❌ git 미포함 | ~18MB | 300,000 | 대여 이력 (분할 5) |
| `bike_rent_6.csv` | ❌ git 미포함 | ~19MB | 315,723 | 대여 이력 (분할 6) |
| `bike_shop.csv` | ✅ 추적됨 | ~90KB | - | 대여소 위치 정보 |

> `bike_rent_*.csv`는 합계 약 130MB로 용량이 커 git 추적에서 제외했습니다(`.gitignore`).
> 아래 안내대로 이 폴더에 직접 배치하면 실습 노트북이 그대로 동작합니다.

## 데이터 배치 방법

1. 따릉이 대여 이력 CSV 6개(`bike_rent_1.csv` ~ `bike_rent_6.csv`)를 준비합니다.
   - 출처: 서울 열린데이터광장 — 서울특별시 공공자전거 이용정보(시간대별)
     <https://data.seoul.go.kr/>
   - 또는 강의에서 제공한 원본 파일을 사용합니다.
2. 받은 파일을 **이 폴더(`sesacstudy/0601/bikerental-data/`)** 에 그대로 넣습니다.
3. 인코딩은 **EUC-KR(CP949)** 입니다. pandas로 읽을 때:

   ```python
   import pandas as pd

   df = pd.read_csv(
       "sesacstudy/0601/bikerental-data/bike_rent_1.csv",
       encoding="cp949",
   )
   ```

## 컬럼 스키마

### `bike_rent_*.csv` (대여 이력)

| 컬럼 | 설명 |
|------|------|
| 자전거번호 | 자전거 식별 번호 (예: `SPB-22040`) |
| 대여일시 | 대여 시각 (예: `2019-06-03 8:49`) |
| 대여 대여소번호 | 대여한 대여소 번호 |
| 대여 대여소명 | 대여한 대여소 이름 |
| 이용시간 | 이용 시간(분) |
| 이용거리 | 이용 거리(m) |

### `bike_shop.csv` (대여소 정보)

| 컬럼 | 설명 |
|------|------|
| 구분 | 자치구 등 구분 |
| 대여소번호 | 대여소 번호 |
| 대여소명 | 대여소 이름 |
| 위도 | 위도 (latitude) |
| 경도 | 경도 (longitude) |
| 설치대수 | 거치대 설치 수 |
