# 테스트 이미지 폴더

예측할 이미지를 이 폴더에 넣으세요. **파일명 제한 없음** — jpg / jpeg / png 이면
`python main.py` 실행 시 전부 예측 대상이 됩니다(특정 파일만: `python main.py 0.5 <경로>`).

예측 결과(바운딩 박스 시각화 PNG)는 `../predictions/prediction_<이름>.png` 로 저장됩니다.

> **이 폴더의 이미지와 `../predictions/` 결과물은 git 에 추적되지 않습니다** (이 README 제외).
> 테스트 이미지에 인물 사진이 포함될 수 있어 개인정보 보호를 위해 저장소에 올리지 않는
> 방침입니다 — 사용자가 직접 이미지를 배치하는 구조입니다.
